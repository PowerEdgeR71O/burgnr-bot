# burgnr-bot
The source code of the Burg.nr bot, powered by the API.

## Information
Burg.nr is a free, no ads link shortener which has an API, so I used it to let people make shortened links from discord. 

## API Docs
It can be found at https://burg.nr/api

## Requirements
- An VPS, Bot Hosting Server or a Code-Server
- Python 3.10 or newer
- Internet Connection
- Git

## Installation 
Start by cloning the repository: ```git clone github.com/PowerEdgeR71O/burgnr-bot```, then ```cd burgnr-bot```. Install all required dependencies by running ```pip install -r requirements.txt```.

That's all for this step.

## Starting the Bot
You must run:
export DISCORD_TOKEN="your-token"
python3 bot.py
